# Porta Wishlist

Feature ideas and improvements to implement when time allows.

---

## Chat & Conversations

- [ ] **Collapse assistant responses** — Toggle in the top bar to hide all assistant/system messages, showing only user messages for quick navigation through a long conversation.
- [ ] **Collapsible message groups** — Click to collapse/expand individual assistant responses or step groups.
- [ ] **Jump to user message** — Quick-nav buttons or a mini-map to jump between your own messages.
- [ ] **Search within conversation** — Cmd+F style search across messages in the current chat.

## Rendering & Debugging

- [ ] **Identify unrendered steps** — Console logging is now in place (`[stepsToMessages]` prefix). Open dev tools → Console to see any step types hitting the catch-all. Promote them to first-class renderers as needed.
- [ ] **Render all step tool arguments** — Show expandable JSON for any generic step's tool call arguments.

## Attachments & Media

- [ ] **Upload attachments from browser** — Enable file/image uploads directly from the web UI (not just forwarded from the agent).
- [ ] **Paste image from clipboard** — Cmd+V to attach screenshots or images.

## Swiper & Navigation

- [ ] **Swipe gestures** — Swipe left/right on the swiper to switch conversations (like iOS tab bar).
- [ ] **Drag to reorder pinned chips** — Rearrange pinned conversations via drag-and-drop.
- [ ] **Conversation grouping** — Group swiper chips by project with section headers.

## Settings & Theming

- [ ] **Export/import settings** — Share appearance configurations across devices.
- [ ] **Custom themes** — Save full theme presets beyond the built-in dark/midnight/warm.
- [ ] **Per-conversation color coding** — Tag conversations with colors beyond project-level colors.

---

*Add ideas freely — prefix with `- [ ]` to keep them trackable.*
